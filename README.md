# Portfolio Website

My personal portfolio, built with HTML, CSS and vanilla JavaScript.

**Live site:** https://yourusername.github.io

## Features
- Responsive layout (works on phones and desktops)
- Light and dark mode that remembers your choice
- Mobile navigation menu
- Deployed with GitHub Pages

## Run locally
Open `index.html` in your browser. No build step needed.

## What I learned
- Semantic HTML and CSS variables
- Flexbox and Grid layouts
- DOM manipulation and localStorage
- Git, GitHub and GitHub Pages deployment
